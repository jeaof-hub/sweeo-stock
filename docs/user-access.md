# สิทธิ์ผู้ใช้ SWEEO Stock

| ดูยอดคงเหลือ | ✓ | ✓ | ✓ | ✓ | ✓ |
| ดูที่เก็บ จุดสั่งผลิต ยอดขายเฉลี่ย | | ✓ | ✓ | ✓ | ✓ |

| บันทึกรับเข้าและส่งออก | | | ✓ | ✓ | ✓ |

| ลบรายการของผู้อื่นหรือย้อนหลัง | | | | ✓ | ✓ |
| ปรับยอด เพิ่มสินค้า และแก้ไขสินค้า | | | | ✓ | ✓ |
| ส่งออก Excel และดูรายการที่ถูกลบ | | | | ✓ | ✓ |

| ดูรายชื่อ/อีเมลผู้ใช้ และจัดการบัญชี | | | | | ✓ |

บัญชีเดิมที่เป็น `editor` ย้ายเป็น `warehouse`; `viewer` ย้ายเป็น `sales` โดย SQL migration `08_role_matrix_and_audit.sql` ผู้ก่อตั้งยังมีได้เพียงบัญชีเดียวและเปลี่ยนสิทธิ์ผู้ก่อตั้งผ่านเว็บไม่ได้

ฐานข้อมูลบังคับสิทธิ์อ่านและเขียนผ่าน Row Level Security. รายการที่ถูกลบจะยังอยู่ในฐานข้อมูล และผู้จัดการ/ผู้ก่อตั้งดูได้ในแท็บรายการที่ถูกลบ. ตาราง `stock_audit` บันทึกค่าก่อนและหลังการเพิ่ม/แก้/ลบสินค้าและรายการรับเข้า/ส่งออกจาก trigger ของฐานข้อมูล โดยผู้ก่อตั้งอ่านได้เพียงคนเดียว. Log นี้เริ่มนับจากวันที่ติดตั้ง migration; ไม่สามารถย้อนสร้างเหตุการณ์ก่อนหน้าได้.

การลบในวันเดียวกันหมายถึงวันปฏิทินตามเขตเวลา `Asia/Bangkok` จากเวลาที่ระบบบันทึกรายการจริง ไม่ใช่วันที่ที่กรอกในเอกสาร. ฝ่ายคลังสินค้าลบได้เฉพาะรายการที่ `created_by` เป็นบัญชีของตนเอง.

การสร้างผู้ใช้และเปลี่ยนสิทธิ์ผ่าน Edge Function `manage-users` ตรวจตัวตนผ่าน Supabase Auth และตรวจว่า `staff.role = founder` และบัญชียังเปิดใช้งานอยู่ทุกครั้ง. เว็บไม่มี service-role key. ผู้ก่อตั้งตั้งรหัสผ่านสมาชิกได้โดยไม่ส่งอีเมลเชิญ และควรแจ้งรหัสผ่านทางช่องทางส่วนตัว.
